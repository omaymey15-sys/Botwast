# 🤖 BotWast - WhatsApp Auto-Reply Bot

Une application Android qui automatise les réponses WhatsApp en détectant les messages entrants et en répondant selon des règles pré-définies.

## ✨ Fonctionnalités Principales

- ✅ **Détection automatique** des messages WhatsApp
- 🤖 **Réponses intelligentes** basées sur des règles
- 👥 **Sélection de contacts** autorisés
- ⏱️ **Délai configurable** avant réponse
- 🔇 **Mode silencieux** programmable
- 📊 **Statistiques en temps réel**
- 💾 **Export/Import** de configuration
- 🎨 **Interface Material Design**

## 📱 Prérequis

- Android 7.0+ (API 24)
- Kotlin 1.9+
- Gradle 8.1+
